Name-based checks for applicants in Ontario

Ontario’s Police Record Checks Reform Act, 2015 sets three standard types of police record check: a criminal record check, a criminal record and judicial matters check, and a vulnerable sector check. Organizations in Ontario often use those names when they ask for a check, so read the request carefully.

We offer CPIC and CRJMC name-based checks. A vulnerable sector check is a separate, more thorough check for positions of trust with vulnerable people, and under the Act it is conducted by police. If you were asked for one, confirm with the organization what it accepts.

Common reasons for a check in Ontario

  • Employment and new-hire screening
  • Volunteering with schools, sports clubs, charities and community groups
  • Rental and housing applications that ask for a check
  • Professional bodies and licensing applications that name the check they need
  • Roles with children or vulnerable people, which may call for a vulnerable sector check instead

Which check should I choose?

The organization asking for your check decides which type it accepts. Order the one it names, a CPIC check or a CRJMC. If it only says “criminal record check”, ask which type it accepts. Compare CPIC and CRJMC.
